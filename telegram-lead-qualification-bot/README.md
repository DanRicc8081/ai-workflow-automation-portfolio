# 01-telegram-lead-qualification-bot/README.md

AI-powered Telegram workflow that classifies incoming messages, logs leads to Google Sheets, routes requests by intent, and sends automated replies.

## Workflow

Telegram → Make → OpenAI → JSON Parse → Google Sheets → Router → Telegram Reply

## Intents

- BOOKING
- PRICING
- SUPPORT
- OTHER

## Tools

- Make.com
- OpenAI
- Telegram Bot
- Google Sheets

## Status

Built as part of an entry-level automation/workflow portfolio.
